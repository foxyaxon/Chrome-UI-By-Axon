##AXON UI 28.0.0
Premium UI Experience
Transform your Chrome into a clean, immersive and personalized experience with Axon UI.

Axon UI replaces the standard Boring UI with a beautiful customizable dashboard designed to keep everything you need within reach — while keeping the interface minimal, smooth and distraction-free.
_________________
FEATURES
-----------------
🖼️ Custom Wallpapers — Set your own image or video wallpaper.
🎬 Default Live Wallpaper — Comes with a built-in animated wallpaper for an instant premium look.
🕐 Customizable Clock — Choose different clock styles, sizes and display options.
🔎 Multiple Search Engines — Google, Bing, DuckDuckGo and Yahoo.
🚀 Custom Shortcuts — Quickly access your favorite websites directly from the New Tab.
🔖 Bookmarks — Access your Chrome bookmarks from the Axon UI interface.
🎨 Customizable Appearance — Adjust accent colors, transparency, blur, overlay and UI scale.
🪟 Glass / Solid / Minimal UI — Choose the visual style that fits your setup.
🔊 UI Sounds — Optional click and typing sounds for a more immersive experience.
📐 Responsive UI Scaling — Adjust the interface size to suit your screen.
📝 Widgets — Personalize your dashboard with useful widgets.
⚡ Smooth Performance — Designed to provide a fast and lightweight New Tab experience.
💾 Persistent Settings — Your customization stays saved across new tabs.
🎯 Built for Personalization

Whether you want a minimal workspace, gaming dashboard, aesthetic setup, or immersive wallpaper experience, Axon UI lets you build your own New Tab.

PRIVACY
-----------------
Axon UI is designed with privacy in mind. Your personal customization and locally stored data are kept within the extension/browser environment and are not required to create an account.
